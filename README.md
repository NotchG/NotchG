## 👋 About me

I'm **Achmed Fidel Ghibran Bn**, a developer who likes turning ideas into things people can actually use.

- 🔊 Currently building **[carcal](https://github.com/NotchG/carcal)**, which calibrates a car audio system automatically, and my own **[tuning app](https://github.com/NotchG/el-pa-4.6-dsp-re)** for the Rainbow EL-PA 4.6 DSP amp
- 🛍️ Also building **[smallshoplp](https://github.com/NotchG/smallshoplp)**, which has Claude Code plan and build a landing page for each small shop it finds on Google Maps
- 🌐 On the web I reach for **Next.js + TypeScript** up front and **Go** or **Python** behind it, with **Docker** for dev
- 📱 For apps I use **Flutter + Firebase**, or wrap one web codebase with **Capacitor** and **Electron**
- 🧠 Also dabbled in computer vision with **Python + OpenCV** and game dev with **Unity**
- 🎓 Built a lot of this with friends at **BINUS University**
